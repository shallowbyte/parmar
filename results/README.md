Key fields beyond the obvious ones:

| field | meaning |
|---|---|
| `row_id` | stable hash of the cell's parameters — the same cell has the same id across runs and machines, which is what makes resume and `rerun-cell` work |
| `packed_bytes` | bytes actually handed to the compressor (the packed token stream). Not the corpus size and not the compressed output — this is the quantity that sets the `xz` block count |
| `round_trip_verified` | **the gate.** False means the ratio on that row is not trustworthy and the analysis excludes it |
| `unsafe_boundary_cuts` | chunks that had no tokenizer-safe cut point in the lookahead window. Non-zero means that row's token stream depends on chunk size |
| `peak_rss_mb` | peak resident set of the cell's process tree, sampled by the parent. `null` if `psutil` was unavailable — never guessed |

## Provenance note

Rows are appended and fsynced as each cell finishes, so an interrupted sweep never loses completed work. A later row for the same `(row_id, corpus_tier)` supersedes an earlier one, which is how `matrix.py rerun-cell` corrections are applied without editing history. `analyze.py` de-duplicates on that key.

Absolute paths are rewritten to repo-relative form by `../scrub_paths.py` before publication.
